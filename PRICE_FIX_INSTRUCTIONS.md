# Исправление проблем с ценами в WooCommerce

## Проблема
Цены в WooCommerce отображаются неправильно:
- Вместо 135000 руб. показывается 1350 руб.
- Проблема затрагивает корзину, чекаут, заказы и email уведомления
- Неправильное количество товаров (×1500 вместо разумного количества)

## Решение
Создан комплексный код для исправления всех проблем с ценами.

## Установка

### Вариант 1: Добавить в functions.php темы
1. Откройте файл `functions.php` вашей активной темы
2. Скопируйте весь код из файла `woocommerce-price-fix.php`
3. Вставьте код в конец файла `functions.php` (но перед закрывающим тегом `?>` если он есть)

### Вариант 2: Создать плагин
1. Создайте папку `woocommerce-price-fix` в директории `/wp-content/plugins/`
2. Скопируйте файл `woocommerce-price-fix.php` в эту папку
3. Добавьте в начало файла заголовок плагина:

```php
<?php
/**
 * Plugin Name: WooCommerce Price Fix
 * Description: Исправляет проблемы с отображением цен в WooCommerce
 * Version: 1.0
 * Author: Your Name
 */
```

4. Активируйте плагин в админке WordPress

## Что исправляет код

### 1. Автоматическое исправление цен
- Определяет слишком маленькие цены (менее 100 руб.) и умножает на 100
- Исправляет цены в копейках/центах
- Корректирует неразумное количество товаров

### 2. Все области WooCommerce
- **Корзина**: цены товаров, подытоги, общая сумма
- **Чекаут**: все расчеты и итоговые суммы
- **Страницы товаров**: обычные и вариативные товары
- **Заказы**: итоги заказов и строки товаров
- **Email уведомления**: исправление в письмах клиентам
- **Блоки Gutenberg**: современные блоки WooCommerce

### 3. Дополнительные функции
- CSS стили для правильного отображения
- JavaScript для исправления цен после AJAX загрузки
- Логирование исправлений для отладки
- Функция принудительного обновления цен в базе данных

## Настройка

### Основные параметры
Основная логика исправления находится в функции `correct_price_value()`:

```php
// Если цена меньше 100 рублей - умножаем на 100
if ($price > 0 && $price < 100) {
    $potential_price = $price * 100;
    if ($potential_price <= 1000000) { // Максимум 1 млн руб.
        return $potential_price;
    }
}
```

### Ручное исправление конкретной цены
```php
// Использование функции ручного исправления
$corrected_price = manual_price_correction(13.50, 100); // Результат: 1350
```

### Принудительное обновление всех цен в базе данных
Добавьте в админку кнопку для обновления:

```php
// Добавить в админку
function add_price_fix_admin_page() {
    add_submenu_page(
        'woocommerce',
        'Исправление цен',
        'Исправление цен',
        'manage_woocommerce',
        'price-fix',
        'price_fix_admin_page'
    );
}
add_action('admin_menu', 'add_price_fix_admin_page');

function price_fix_admin_page() {
    if (isset($_POST['fix_prices'])) {
        force_update_product_prices();
        echo '<div class="notice notice-success"><p>Цены обновлены!</p></div>';
    }
    ?>
    <div class="wrap">
        <h1>Исправление цен</h1>
        <form method="post">
            <input type="submit" name="fix_prices" class="button-primary" value="Исправить все цены в базе данных">
        </form>
    </div>
    <?php
}
```

## Специфические исправления

### Для количества товаров
Если видите количество ×1500, код автоматически попытается исправить:
```php
if ($quantity > 1000) {
    if ($quantity % 1000 == 0) {
        $corrected_qty = $quantity / 1000; // 1500 → 1.5
    } else if ($quantity % 100 == 0) {
        $corrected_qty = $quantity / 100; // 1500 → 15
    }
}
```

### Для email уведомлений
Код использует буферизацию и регулярные выражения для исправления цен в письмах:
```php
// Исправляет паттерны типа "1350 руб." на правильные цены
$content = preg_replace_callback(
    '/(\d+)&nbsp;<span class="woocommerce-Price-currencySymbol">руб\.<\/span>/',
    function($matches) {
        $price = intval($matches[1]);
        $corrected_price = correct_price_value($price);
        // Возвращает исправленную цену
    },
    $content
);
```
