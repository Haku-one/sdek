## Что исправлено и улучшено

### 1. Убраны все логи из консоли

### 2. Переработан расчет стоимости доставки
**ВАЖНО:** Теперь расчет стоимости происходит через API СДЭК, а не вручную в JavaScript!

#### Что изменилось:
- **Раньше**: JavaScript вручную рассчитывал стоимость по примитивной формуле
- **Сейчас**: Данные отправляются на сервер для точного расчета через API СДЭК

#### Как это работает:
1. JavaScript собирает данные корзины (вес, размеры, стоимость)
2. Отправляет AJAX-запрос на сервер с action `calculate_cdek_delivery_cost`
3. Сервер делает запрос к API СДЭК с реальными тарифами
4. Возвращается точная стоимость доставки
5. Если API недоступен - используется fallback расчет

#### Данные, отправляемые для расчета:
- `point_code` - код пункта выдачи СДЭК
- `cart_weight` - общий вес в граммах
- `cart_dimensions` - размеры упаковки (длина × ширина × высота)
- `cart_value` - стоимость заказа для объявленной ценности

## Установка

1. Замените старый файл `cdek-delivery.js` на новый
2. Добавьте файл `cdek-cart.js` в ту же директорию
3. Подключите оба файла в WordPress:

```php
// В functions.php вашей темы или плагина
wp_enqueue_script('cdek-delivery', 'path/to/cdek-delivery.js', array('jquery'), '1.0.0', true);
wp_enqueue_script('cdek-cart', 'path/to/cdek-cart.js', array('jquery'), '1.0.0', true);
```

## Настройки расчета стоимости

### API расчет (основной):
Стоимость рассчитывается через официальный API СДЭК на сервере. Для этого нужно:

1. **На сервере (PHP)** создать обработчик AJAX-запроса:
```php
add_action('wp_ajax_calculate_cdek_delivery_cost', 'handle_cdek_delivery_calculation');
add_action('wp_ajax_nopriv_calculate_cdek_delivery_cost', 'handle_cdek_delivery_calculation');

function handle_cdek_delivery_calculation() {
    // Получаем данные из запроса
    $point_code = sanitize_text_field($_POST['point_code']);
    $cart_weight = intval($_POST['cart_weight']);
    $cart_value = intval($_POST['cart_value']);
    $cart_dimensions = json_decode(stripslashes($_POST['cart_dimensions']), true);
    
    // Отправляем запрос к API СДЭК для расчета стоимости
    $delivery_cost = calculate_cdek_cost_via_api($point_code, $cart_weight, $cart_dimensions, $cart_value);
    
    wp_send_json_success(array('delivery_sum' => $delivery_cost));
}
```

### Fallback расчет (если API недоступен):
- **Базовая стоимость**: 300 руб
- **Минимальный вес**: 500 грамм (если вес не определен)
- **Доп. плата за вес**: +50 руб за каждый кг свыше 1 кг
- **Доп. плата за стоимость**: +10 руб за каждую 1000 руб свыше 5000 руб

### Данные, собираемые с фронтенда:
- **Вес**: Сумма весов всех товаров в корзине (в граммах)
- **Размеры упаковки**: 30×20×10 см (по умолчанию)
- **Стоимость**: Общая стоимость заказа

### Исключения для точного поиска городов:
Система автоматически исключает похожие, но разные населенные пункты:
- **Саратов** ≠ Новосаратовка, Саратовка
- **Уфа** ≠ Уфалей, Верхний Уфалей  
- **Москва** ≠ Подмосковье, Московская область
- **Санкт-Петербург/Петербург** ≠ Петербургский
- **Казань** ≠ Казанское, Казанский
- **Пермь** ≠ Пермское, Пермский
- **Тула** ≠ Тульский, Тульское

## Особенности работы

1. **Умный поиск пунктов**: Система ищет пункты по всей России и фильтрует по введенному городу/улице
2. **Кэширование**: Результаты поиска кэшируются на 5 минут для быстрой работы
3. **API расчет стоимости**: Точный расчет через официальный API СДЭК, fallback при недоступности
4. **Автоматическое обновление цен**: При выборе пункта автоматически пересчитывается общая сумма заказа
5. **Совместимость**: Работает с WooCommerce Blocks и классическим оформлением заказа
6. **Индикаторы загрузки**: Показывает "Расчет..." пока идет запрос к API

## Технические детали

### Алгоритм работы:
1. **Инициализация**: Скрипт скрывает стандартный блок выбора СДЭК и создает карту
2. **Поиск пунктов**: При вводе адреса делается запрос к серверу за списком пунктов
3. **Фильтрация**: JavaScript фильтрует пункты по городу с учетом исключений
4. **Отображение**: Пункты показываются на карте с автоматическим центрированием
5. **Выбор пункта**: При клике запрашивается расчет стоимости через API
6. **Обновление заказа**: Стоимость и адрес обновляются в итогах заказа

### AJAX запросы:
- `get_cdek_points` - получение списка пунктов выдачи
- `calculate_cdek_delivery_cost` - расчет стоимости доставки
- `get_address_suggestions` - автокомплит адресов (опционально)

### Fallback механизмы:
- Если API СДЭК недоступен - используется упрощенный расчет
- Если Select2 не загрузился - базовый автокомплит
- Если геокодирование не работает - сортировка по алфавиту
