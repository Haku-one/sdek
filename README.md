# СДЭК доставка для WooCommerce

Плагин интеграции службы доставки СДЭК для WooCommerce с возможностью выбора пунктов выдачи на интерактивной карте.

## Основные возможности

- **Автоматическое скрытие ненужных полей** - скрывает поля "Населенный пункт", "Область/район" и "Почтовый индекс" при выборе доставки СДЭК
- **Извлечение города из адреса** - автоматически определяет город из поля адреса для поиска пунктов выдачи
- **Интерактивная карта пунктов выдачи** - показывает пункты выдачи СДЭК на Яндекс.Картах
- **Расчет стоимости доставки** - использует API СДЭК для расчета точной стоимости с учетом веса и размеров товаров
- **Поддержка всех единиц измерения** - автоматически конвертирует вес и размеры товаров в нужные единицы

## Установка

1. Скопируйте файлы плагина в папку `/wp-content/plugins/cdek-shipping/`
2. Активируйте плагин в разделе "Плагины" админ-панели WordPress
3. Перейдите в **WooCommerce → СДЭК доставка** для настройки

## Настройка

### 1. Получение учетных данных СДЭК

1. Войдите в [личный кабинет СДЭК](https://lk.cdek.ru/)
2. Перейдите в раздел **Интеграция → API**
3. Получите Account ID и Secure Password
4. Введите их в настройках плагина

### 2. Настройка Яндекс.Карт

1. Зарегистрируйтесь в [консоли разработчика Яндекс](https://developer.tech.yandex.ru/)
2. Создайте новый API-ключ для JavaScript API Карт
3. Введите ключ в настройках плагина

### 3. Настройка способов доставки

1. Перейдите в **WooCommerce → Настройки → Доставка**
2. Выберите зону доставки или создайте новую
3. Добавьте способ доставки **"СДЭК доставка"**
4. Настройте параметры метода доставки

## Использование

### Для администратора

1. **Настройте вес и размеры товаров** в карточках товаров для корректного расчета стоимости
2. **Укажите код города отправления** в настройках плагина
3. **Выберите подходящий тариф** СДЭК в настройках метода доставки

### Для покупателей

1. **Введите адрес с указанием города** в формате: "Москва, ул. Тверская д.1"
2. **Выберите способ доставки** "СДЭК доставка"
3. **Выберите пункт выдачи** на карте или из списка
4. **Завершите оформление заказа**

## Требования

- WordPress 5.0+
- WooCommerce 3.0+
- PHP 7.4+
- Активный аккаунт СДЭК
- API-ключ Яндекс.Карт

## Настройки товаров

Для корректного расчета стоимости доставки обязательно указывайте:

### Вес товара
- Указывается в разделе **"Доставка"** карточки товара
- Поддерживаются единицы: г, кг, фунты, унции
- Автоматически конвертируется в граммы для API СДЭК

### Размеры товара
- Длина, ширина, высота в разделе **"Доставка"**
- Поддерживаются единицы: см, мм, м, дюймы, ярды
- Автоматически конвертируются в сантиметры для API СДЭК

## Форматы адресов

Плагин умеет извлекать город из различных форматов адресов:

- `Москва, ул. Тверская д.1`
- `г. Санкт-Петербург, Невский проспект 123`
- `город Екатеринбург, ул. Ленина 45`

## Поддерживаемые тарифы СДЭК

- **Посылка склад-склад** (136)
- **Посылка склад-дверь** (138)
- **Экономичная посылка склад-склад** (233)
- **Экономичная посылка склад-дверь** (234)

## Устранение проблем

### Не загружаются пункты выдачи
1. Проверьте правильность указания города в адресе
2. Убедитесь, что в городе есть пункты выдачи СДЭК
3. Проверьте корректность учетных данных API

### Не рассчитывается стоимость доставки
1. Убедитесь, что указан вес товаров
2. Проверьте код города отправления в настройках
3. Проверьте подключение к API СДЭК в разделе тестирования

### Карта не отображается
1. Проверьте корректность API-ключа Яндекс.Карт
2. Убедитесь, что ключ имеет доступ к JavaScript API Карт
3. Проверьте консоль браузера на наличие ошибок JavaScript

## Техническая поддержка

При возникновении проблем:

1. Проверьте настройки в разделе **WooCommerce → СДЭК доставка**
2. Используйте функцию **"Проверить подключение к СДЭК"**
3. Проверьте логи WordPress на наличие ошибок
4. Убедитесь, что все требования выполнены

## API Endpoints

Плагин использует следующие методы API СДЭК v2:

- `POST /oauth/token` - получение токена авторизации
- `GET /location/cities` - поиск городов
- `GET /deliverypoints` - получение пунктов выдачи
- `POST /calculator/tarifflist` - расчет стоимости доставки

## Безопасность

- Все пользовательские данные проходят валидацию и санитизацию
- API ключи хранятся в зашифрованном виде в базе данных
- Используется nonce-защита для AJAX запросов
- Токены доступа кэшируются на ограниченное время
