# СДЭК Доставка - Исправления v2.6.4

## ✅ НОВЫЕ ИСПРАВЛЕНИЯ v2.6.4

### 🚀 **Добавлена поддержка постоматов**
- **Изменен параметр API:** `type: 'ALL'` вместо `'PVZ'` для получения всех типов точек
- **Цветовая индикация:** 🟦 Синие метки для ПВЗ, 🟧 Оранжевые метки для постоматов
- **Улучшенные всплывающие окна:** Отображение типа точки (ПВЗ/Постамат)
- **Автоопределение типа:** По полям `type` и `name` из API ответа

### 🗺️ **Принудительное исправление отображения карты**
- **Множественные проверки видимости:** Блок, контейнер, элемент карты
- **Принудительные стили:** `display: block !important` для всех уровней
- **Автоматическая перерисовка:** После инициализации и при переключениях
- **Диагностический скрипт v2:** `debug-map-v2.js` для автоматического исправления

## Исправленные проблемы

### 1. Проблема с фильтрацией ПВЗ по городам через API СДЭК

**Проблема:** 
- API иногда возвращал неправильное количество ПВЗ для конкретных городов
- Отсутствовали необходимые ПВЗ в некоторых городах
- Неправильная работа с `city_code` параметром

**Исправления:**
- ✅ Улучшен метод `get_delivery_points()` с более надежным поиском `city_code`
- ✅ Добавлен альтернативный метод `get_city_code_fuzzy()` для гибкого поиска города
- ✅ Добавлена дополнительная клиентская фильтрация результатов при необходимости
- ✅ Увеличен лимит результатов API до 1000 пунктов
- ✅ Добавлены параметры `country_code=RU` и `size=1000` для более точных результатов
- ✅ Альтернативный поиск по названию города если `city_code` не найден
- ✅ Блокировка поиска для слишком коротких названий городов (менее 3 символов)
- 🆕 **Поддержка постоматов:** `type: 'ALL'` включает ПВЗ и постоматы

### 2. Проблема с реинициализацией карты при переключении вкладок

**Проблема:**
- При переключении "доставка" → "самовывоз" → "доставка" карта не инициализировалась обратно
- Переменная `cdekMap` оставалась `null` или неактивной

**Исправления:**
- ✅ Улучшена функция `initYandexMap()` с дополнительными проверками
- ✅ Добавлена принудительная реинициализация карты при возврате на вкладку "доставка"
- ✅ Улучшен MutationObserver для отслеживания изменений `aria-checked`
- ✅ Добавлено восстановление ПВЗ на карте после реинициализации
- ✅ Добавлены проверки размеров контейнера карты перед инициализацией
- ✅ Улучшена обработка ошибок инициализации карты

### 3. ⚠️ Проблема с отображением карты в блоке `wp-block-cdek-checkout-map-block`

**Проблема:**
- Блок `<div class="wp-block-cdek-checkout-map-block"></div>` остается пустым
- Карта инициализируется, но не отображается визуально

**Исправления:**
- ✅ Улучшен поиск и вставка блока карты в `initCdekDelivery()`
- ✅ Добавлена принудительная вставка HTML карты в блок
- ✅ Добавлены принудительные стили для показа контейнеров
- ✅ Улучшена отладка размещения карты
- 🆕 **Принудительная видимость:** Множественные проверки и стили `!important`
- 🆕 **Автоматическая перерисовка:** После инициализации карты

## Диагностика и устранение проблем

### 🚀 БЫСТРОЕ ИСПРАВЛЕНИЕ v2 (если карта не отображается):

**Вставьте в консоль браузера (F12):**
```javascript
// Загрузите содержимое файла debug-map-v2.js
// Или используйте быстрое исправление:

const wpBlock = document.querySelector('.wp-block-cdek-checkout-map-block');
if (wpBlock) {
    wpBlock.innerHTML = `<div id="cdek-map-container" style="display: block !important;">
        <h4>🟦 ПВЗ и 🟧 Постоматы СДЭК:</h4>
        <div id="cdek-map" style="width: 100% !important; height: 450px !important; display: block !important;"></div>
    </div>`;
    wpBlock.style.cssText = 'display: block !important; visibility: visible !important; min-height: 500px !important;';
    setTimeout(() => { 
        if (window.initYandexMap) { 
            window.cdekMap = null; 
            window.initYandexMap(); 
        }
    }, 500);
}
```

### Ошибки API и их решения:

- **"Получено ПВЗ от API: 0"** - название города слишком короткое или неточное
- **Карта инициализируется, но не видна** - используйте `debug-map-v2.js`
- **ПВЗ не найдены** - проверьте правильность названия города
- **Только ПВЗ без постоматов** - обновите параметр API на `type: 'ALL'`

## Технические детали

### Новые функции v2.6.4:
- **Поддержка постоматов:** Цветовая индикация и определение типа
- **Принудительная видимость:** Множественные проверки отображения
- **Улучшенная диагностика:** `debug-map-v2.js` с автоисправлением

### Новые методы PHP:
- `get_city_code_fuzzy()` - альтернативный поиск city_code по частичному совпадению

### Улучшенные методы JavaScript:
- `initYandexMap()` - более надежная инициализация карты
- `initCdekDelivery()` - улучшенное размещение карты с принудительной видимостью
- `selectCdekPoint()` - глобальная функция для выбора ПВЗ/постомата
- `calculateDeliveryCost()` - функция расчета стоимости с определением типа
- Обработчики событий переключения доставки
- MutationObserver для отслеживания изменений

### Новые параметры API СДЭК:
- `type: 'ALL'` - **ПВЗ + Постоматы** (вместо только `'PVZ'`)
- `country_code: 'RU'` - фильтр по стране
- `size: '1000'` - увеличенный лимит результатов
- Альтернативный фильтр `city` при отсутствии `city_code`
- Проверка длины названия города (минимум 3 символа)
