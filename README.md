## Файлы

### cdek-delivery.js
Основной файл с функционалом СДЭК доставки:
- Инициализация карты Яндекс
- Поиск и отображение пунктов выдачи
- Расчет стоимости доставки
- Обработка выбора пункта выдачи
- Автокомплит адресов

### cdek-cart.js  
Дополнительный файл для работы с корзиной:
- Исправление отображения в корзине
- Очистка описаний при смене метода доставки
- Мониторинг изменений DOM

## Установка

1. Замените старый файл `cdek-delivery.js` на новый
2. Добавьте файл `cdek-cart.js` в ту же директорию
3. Подключите оба файла в WordPress:

```php
// В functions.php вашей темы или плагина
wp_enqueue_script('cdek-delivery', 'path/to/cdek-delivery.js', array('jquery'), '1.0.0', true);
wp_enqueue_script('cdek-cart', 'path/to/cdek-cart.js', array('jquery'), '1.0.0', true);
```

## Настройки расчета стоимости

### Базовые настройки (в функции `calculateDeliveryCost`):
- **Базовая стоимость**: 200 руб
- **Минимальный вес**: 0.5 кг (если вес не определен)
- **Доп. плата за расстояние**: +150 руб за каждые 100 км свыше 100 км
- **Доп. плата за вес**: +100 руб за каждый кг свыше 1 кг

### Координаты отправления (Саратов):
- Широта: 51.5924
- Долгота: 46.0347

### Исключения для точного поиска городов:
Система автоматически исключает похожие, но разные населенные пункты:
- **Саратов** ≠ Новосаратовка, Саратовка
- **Уфа** ≠ Уфалей, Верхний Уфалей  
- **Москва** ≠ Подмосковье, Московская область
- **Санкт-Петербург/Петербург** ≠ Петербургский
- **Казань** ≠ Казанское, Казанский
- **Пермь** ≠ Пермское, Пермский
- **Тула** ≠ Тульский, Тульское

## Особенности работы

1. **Умный поиск пунктов**: Система ищет пункты по всей России и фильтрует по введенному городу/улице
2. **Кэширование**: Результаты поиска кэшируются на 5 минут для быстрой работы
3. **Автоматическое обновление цен**: При выборе пункта автоматически пересчитывается общая сумма заказа
4. **Совместимость**: Работает с WooCommerce Blocks и классическим оформлением заказа
