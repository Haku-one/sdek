# СДЭК Доставка для WooCommerce

Плагин для интеграции доставки СДЭК с упрощенной формой адреса и картой пунктов выдачи.

## Возможности

- ✅ Интеграция с API СДЭК v2
- ✅ Автоматический расчет стоимости доставки через API
- ✅ Интерактивная карта с пунктами выдачи СДЭК
- ✅ Автокомплит адресов
- ✅ Отображение габаритов товаров в оформлении заказа
- ✅ Поддержка WooCommerce блоков
- ✅ Адаптивный дизайн
- ✅ Кэширование данных для быстрой работы

## Установка

1. Загрузите все файлы плагина в папку `/wp-content/plugins/cdek-delivery/`
2. Активируйте плагин в админке WordPress
3. Перейдите в **Настройки → СДЭК Доставка** для настройки

## Настройка

### 1. Получение API ключей СДЭК

1. Зарегистрируйтесь в [личном кабинете СДЭК](https://lk.cdek.ru/)
2. Перейдите в раздел **Интеграция → API**
3. Создайте новое приложение и получите:
   - **Account (Client ID)**
   - **Secure Password (Client Secret)**

### 2. Настройка плагина

1. Перейдите в **Настройки → СДЭК Доставка**
2. Введите полученные API ключи
3. Укажите код города отправителя (по умолчанию 51 - Саратов)
4. При необходимости включите тестовый режим
5. Сохраните настройки
6. Нажмите **Проверить подключение** для тестирования API

### 3. Настройка зон доставки

1. Перейдите в **WooCommerce → Настройки → Доставка**
2. Выберите нужную зону доставки или создайте новую
3. Добавьте метод доставки **"СДЭК — Пункт выдачи"**
4. Настройте параметры метода доставки

### 4. Настройка габаритов товаров

Для корректного расчета стоимости доставки обязательно укажите габариты товаров:

1. Перейдите в **Товары → Все товары**
2. Отредактируйте товар
3. В разделе **Доставка** укажите:
   - **Вес** (в граммах)
   - **Длина** (в см)
   - **Ширина** (в см)  
   - **Высота** (в см)

## Как работает

### Для покупателя

1. На странице оформления заказа покупатель видит блок с габаритами товаров
2. В поле адреса вводит город доставки
3. После выбора метода доставки "СДЭК" появляется карта
4. На карте отображаются все доступные пункты выдачи в указанном городе
5. При выборе пункта автоматически рассчитывается точная стоимость доставки
6. Стоимость обновляется в общей сумме заказа

### Расчет стоимости

Плагин использует официальный API СДЭК для точного расчета стоимости доставки на основе:
- Веса товаров
- Габаритов товаров  
- Стоимости товаров (для страхования)
- Выбранного пункта выдачи
- Города отправителя

При недоступности API используется fallback-расчет.

## Коды городов СДЭК

Популярные коды городов для настройки отправителя:

- **Москва**: 44
- **Санкт-Петербург**: 137
- **Новосибирск**: 114
- **Екатеринбург**: 49
- **Казань**: 145
- **Нижний Новгород**: 115
- **Самара**: 51 (Саратов - по умолчанию)

### AJAX обработчики

- `get_cdek_points` - Получение списка пунктов выдачи
- `calculate_cdek_delivery_cost` - Расчет стоимости доставки
- `get_address_suggestions` - Автокомплит адресов
- `test_cdek_connection` - Проверка подключения к API

- Токены авторизации кэшируются на время их действия
- Список пунктов выдачи кэшируется на 5 минут
- Используется встроенная система кэширования WordPress

## Поддержка и разработка

### Отладка

Включите логирование WordPress для просмотра отладочной информации:

```php
// wp-config.php
define('WP_DEBUG', true);
define('WP_DEBUG_LOG', true);
```

Логи сохраняются в `/wp-content/debug.log`

### Часто встречающиеся проблемы

**Не загружается карта:**
- Проверьте API ключ Яндекс.Карт
- Убедитесь что включен JavaScript

**Не рассчитывается стоимость:**
- Проверьте API ключи СДЭК
- Убедитесь что у товаров указаны габариты
- Проверьте код города отправителя

**Не отображаются пункты выдачи:**
- Проверьте подключение к API СДЭК
- Убедитесь что город указан корректно

**Отображаются поля "Город", "Область":**
- Плагин автоматически скрывает эти поля
- Если поля видны, очистите кэш браузера
- Проверьте что плагин активен

**Не обновляется стоимость при смене пункта:**
- Плагин автоматически очищает предыдущий выбор
- При смене города выбранный пункт сбрасывается
- Стоимость пересчитывается автоматически
