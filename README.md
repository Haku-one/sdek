# СДЭК Доставка для WooCommerce

Плагин для интеграции доставки СДЭК с упрощенной формой адреса и интерактивной картой пунктов выдачи.

## Особенности

- ✅ Упрощенная форма адреса (убраны поля: город, область, почтовый индекс)
- ✅ Интерактивная карта Яндекс с пунктами выдачи СДЭК
- ✅ Автоматический поиск пунктов выдачи по адресу
- ✅ Расчет стоимости доставки через API СДЭК
- ✅ Сохранение выбранного пункта выдачи в заказе
- ✅ Использование веса товаров из WooCommerce
- ✅ Совместимость с WooCommerce 10.0.2

## Требования

- WordPress 5.0+
- WooCommerce 8.0+
- PHP 7.4+
- Аккаунт СДЭК с API доступом
- API ключ Яндекс.Карт

## Установка

1. Загрузите все файлы плагина в папку `/wp-content/plugins/cdek-delivery/`
2. Активируйте плагин в админ-панели WordPress
3. Перейдите в Настройки → СДЭК Доставка для конфигурации

## Настройка

### 1. Настройка СДЭК API

1. Получите учетные данные в личном кабинете СДЭК:
   - Идентификатор аккаунта
   - Пароль (Secure password)

2. Введите их в настройках плагина

### 2. Настройка Яндекс.Карт

1. Получите API ключ на [developer.tech.yandex.ru](https://developer.tech.yandex.ru/)
2. Включите в настройках ключа:
   - JavaScript API
   - Геокодер
3. Введите ключ в настройках плагина

### 3. Настройка WooCommerce

1. Перейдите в WooCommerce → Настройки → Доставка
2. Создайте зону доставки или выберите существующую
3. Добавьте метод доставки "СДЭК Доставка"
4. Настройте параметры метода:
   - Включите метод
   - Укажите название
   - Установите фиксированную стоимость или оставьте пустой для автоматического расчета
   - Укажите код города отправления (44 - Москва, 137 - СПб)

### 4. Настройка товаров

Убедитесь, что у всех товаров указан вес в граммах:
1. Перейдите к редактированию товара
2. На вкладке "Доставка" укажите вес в поле "Вес (г)"
3. При необходимости укажите размеры

## Использование

### Для покупателей

1. При оформлении заказа выберите способ доставки "СДЭК - Пункт выдачи"
2. Введите адрес в формате: "Город, улица, дом" (например: "Москва, ул. Ленина, д. 1")
3. Система автоматически найдет ближайшие пункты выдачи СДЭК
4. Выберите подходящий пункт на карте или в списке
5. Завершите оформление заказа

### Для администраторов

1. Информация о выбранном пункте выдачи отображается в деталях заказа
2. Можно проверить подключение к API в настройках плагина
3. Все ошибки логируются в журнал WordPress

## API Endpoints

Плагин использует следующие endpoints СДЭК API v2:
- `/oauth/token` - получение токена авторизации
- `/deliverypoints` - получение списка пунктов выдачи
- `/calculator/tariff` - расчет стоимости доставки

## Скрытие полей формы

Плагин автоматически скрывает следующие поля в форме доставки:
- Населённый пункт (`shipping_city`)
- Область / район (`shipping_state`) 
- Почтовый индекс (`shipping_postcode`)

Эти поля скрываются через CSS и исключаются из обработки формы.

## Техническая поддержка

При возникновении проблем:

1. Проверьте корректность API ключей в настройках
2. Убедитесь, что у товаров указан вес
3. Проверьте настройки зон доставки в WooCommerce
4. Используйте тестовый режим для отладки
