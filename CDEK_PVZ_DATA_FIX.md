# Исправление проблемы с сохранением данных ПВЗ СДЭК

## Проблема
В заказах не сохранялись данные о выбранном пункте выдачи СДЭК и стоимости доставки. На странице благодарности показывалось "Доставка: Выберите пункт выдачи", а итоговая сумма не включала стоимость доставки.

## Причина
Данные о выбранном ПВЗ и стоимости доставки не передавались из JavaScript в форму заказа или не сохранялись в WooCommerce сессии.

## Исправления

### 1. ✅ Добавлено расширенное логирование
В метод `save_cdek_point_data()` добавлено подробное логирование для отслеживания:
- Данных из `$_POST`
- Данных из WooCommerce сессии
- Процесса сохранения

### 2. ✅ Добавлен AJAX метод для сохранения в сессии
Создан новый AJAX метод `ajax_save_cdek_data_to_session()`:
```php
// Сохраняет данные ПВЗ и стоимость доставки в WooCommerce сессию
public function ajax_save_cdek_data_to_session()
```

### 3. ✅ Создан обработчик сессии JavaScript
Новый файл `assets/js/cdek-session-handler.js`:
- Следит за изменениями в скрытых полях СДЭК
- Автоматически сохраняет данные в WooCommerce сессии
- Использует MutationObserver для отслеживания динамических изменений
- Периодически проверяет и сохраняет данные

### 4. ✅ Резервное сохранение из сессии
В методы `save_cdek_point_data()` и `update_order_shipping_cost()` добавлено:
- Проверка данных в WooCommerce сессии
- Сохранение из сессии если данные в POST отсутствуют
- Дополнительное логирование всего процесса

### 5. ✅ Улучшен метод обновления стоимости доставки
Метод `update_order_shipping_cost()` теперь:
- Получает данные из POST или WooCommerce сессии
- Обновляет стоимость доставки в заказе
- Обновляет название метода доставки с названием ПВЗ
- Пересчитывает общую стоимость заказа

## Как работает исправление

### JavaScript уровень:
1. `cdek-delivery.js` - создает скрытые поля при выборе ПВЗ
2. `cdek-session-handler.js` - отслеживает эти поля и сохраняет данные в сессии через AJAX

### PHP уровень:
1. `ajax_save_cdek_data_to_session()` - сохраняет данные в WooCommerce сессии
2. `save_cdek_point_data()` - сохраняет данные в мета-полях заказа (из POST или сессии)
3. `update_order_shipping_cost()` - обновляет стоимость доставки в заказе

## Проверка исправлений

### 1. Включите логирование
Откройте файл `wp-content/debug.log` и следите за сообщениями начинающимися с `CDEK DEBUG:`

### 2. Оформите тестовый заказ
1. Перейдите на страницу оформления заказа
2. Выберите доставку СДЭК
3. Выберите пункт выдачи на карте
4. Убедитесь что отображается стоимость доставки
5. Оформите заказ

### 3. Проверьте результат
После оформления заказа:
- На странице благодарности должна отображаться информация о ПВЗ
- В админке WooCommerce в заказе должны быть данные о ПВЗ
- Стоимость доставки должна быть включена в итоговую сумму
- Email уведомления должны содержать информацию о доставке

### 4. Проверьте логи
В `debug.log` должны быть записи:
```
CDEK Session: Данные успешно сохранены в сессии
CDEK DEBUG: Saved point code from session: XXXXX
CDEK DEBUG: Saved delivery cost from WC session: XXX
CDEK DEBUG: Обновлено название метода доставки: Город, Название ПВЗ
```

## Отладка проблем

### Если данные не сохраняются:
1. Проверьте консоль браузера на ошибки JavaScript
2. Убедитесь что файл `cdek-session-handler.js` загружается
3. Проверьте логи на предмет ошибок AJAX

### Если стоимость не обновляется:
1. Проверьте что метод доставки в заказе содержит 'cdek_delivery'
2. Убедитесь что WooCommerce сессии работают корректно

## Файлы изменений
- `cdek-delivery-plugin.php` - основные исправления PHP
- `assets/js/cdek-session-handler.js` - новый обработчик сессии
- Метод `enqueue_scripts()` - подключение нового JS файла
