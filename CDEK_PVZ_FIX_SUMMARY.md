# ИСПРАВЛЕНИЕ ПРОБЛЕМЫ ОТОБРАЖЕНИЯ ПВЗ СДЭК

## Проблема
В файле `assets/js/cdek-delivery.js` не все пункты выдачи заказов (ПВЗ) СДЭК отображались на карте, особенно для разных городов России. Проблема заключалась в том, что:

1. **Неэффективный запрос к API**: JavaScript всегда отправлял запрос с параметром `address: 'Россия'` вместо конкретного города
2. **Ограниченная фильтрация**: Фильтрация ПВЗ происходила только на фронтенде после получения данных
3. **Неоптимальные параметры API**: Не использовались параметры для получения максимального количества ПВЗ

## Внесенные исправления

### 1. JavaScript код (`assets/js/cdek-delivery.js`)

#### Исправлена функция `performCdekSearch`:
- Теперь передается конкретный город вместо "Россия"
- Добавлено логирование для отладки
- Улучшена обработка ответов API

```javascript
// Формируем адрес для поиска - используем конкретный город, если он известен
var searchAddress = 'Россия';
if (window.currentSearchCity) {
    searchAddress = window.currentSearchCity;
}
```

#### Добавлена функция `loadAllCdekPoints`:
- Позволяет загружать все ПВЗ России одним запросом
- Увеличенный таймаут для больших запросов (60 секунд)
- Специальная обработка для отображения всех пунктов

#### Увеличен лимит отображения ПВЗ:
```javascript
var maxPoints = 1000; // Увеличен с 380 до 1000
```

#### Добавлена кнопка "Показать все ПВЗ России":
- Позволяет пользователю загрузить все доступные ПВЗ
- Стильный дизайн с иконкой 🌍
- Обработчик события для загрузки всех пунктов

### 2. PHP код (`cdek-delivery-plugin.php`)

#### Улучшен метод `extract_city_from_address`:
- Обработка случая "Россия" для загрузки всех ПВЗ
- Очистка от префиксов "г.", "город"
- Улучшенное логирование

```php
// Если адрес "Россия", возвращаем пустую строку для поиска по всем городам
if (strtolower($address) === 'россия' || strtolower($address) === 'russia') {
    error_log('СДЭК API: Адрес "Россия" - будем искать по всем городам');
    return '';
}
```

#### Оптимизирован метод `get_delivery_points`:
- Добавлены параметры для получения максимального количества ПВЗ
- Условное добавление параметра города
- Улучшенная обработка различных форматов ответа API
- Увеличенный таймаут запроса

```php
$params = array(
    'type' => 'PVZ',
    'have_cash' => 'true',
    'have_cashless' => 'true',
    'is_handout' => 'true',
    'country_code' => 'RU',
    'size' => 5000, // Максимальное количество результатов
    'page' => 0
);

// Добавляем город только если он указан
if (!empty($city)) {
    $params['city'] = $city;
}
```

#### Улучшена обработка ответа API:
- Проверка различных форматов ответа СДЭК API
- Детальное логирование для отладки
- Обработка ошибок API

## Результат

После внесения исправлений:

1. **✅ Корректная работа с городами**: При поиске конкретного города API получает именно этот город, а не "Россия"
2. **✅ Загрузка всех ПВЗ**: Добавлена возможность загрузить все ПВЗ России через специальную кнопку
3. **✅ Увеличенное количество ПВЗ**: Лимит отображения увеличен с 380 до 1000 пунктов
4. **✅ Оптимизированные API запросы**: Используются правильные параметры для получения максимального количества данных
5. **✅ Улучшенное логирование**: Добавлены подробные логи для отладки проблем

## Как использовать

1. **Поиск по городу**: Введите название города в поле адреса - будут загружены ПВЗ только этого города
2. **Все ПВЗ России**: Нажмите кнопку "🌍 Показать все ПВЗ России" для загрузки всех доступных пунктов выдачи

- Улучшена производительность на мобильных устройствах
- Добавлены эмодзи и цветные логи для лучшей отладки
