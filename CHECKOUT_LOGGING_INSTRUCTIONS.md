# 🔍 Система логирования валидации формы оформления заказа

## Описание

Система логирования создана для диагностики проблем с отправкой формы оформления заказа. Она отслеживает весь процесс валидации, заполнения полей и создания заказа.

## Файлы системы

1. **`checkout-validation-logger.php`** - Основной файл логирования
2. **`view-validation-logs.php`** - Интерфейс для просмотра логов
3. **`CHECKOUT_LOGGING_INSTRUCTIONS.md`** - Данная инструкция

## Установка

### Вариант 1: Подключение через functions.php

Добавьте в файл `functions.php` вашей темы:

```php
// Подключаем систему логирования валидации
require_once(get_template_directory() . '/checkout-validation-logger.php');
```

### Вариант 2: Подключение через плагин

Добавьте в основной файл вашего плагина:

```php
// Подключаем систему логирования
require_once(plugin_dir_path(__FILE__) . 'checkout-validation-logger.php');
```

## Просмотр логов

### Способ 1: Через браузер

1. Разместите файл `view-validation-logs.php` в корне WordPress
2. Откройте в браузере: `https://yoursite.com/view-validation-logs.php`
3. Войдите как администратор

### Способ 2: Через файловую систему

Логи сохраняются в файл: `wp-content/checkout-validation-debug.log`

### Способ 3: Через админку WordPress

Добавьте в `functions.php`:

```php
// Добавляем страницу в админку
add_action('admin_menu', 'add_checkout_logs_page');

function add_checkout_logs_page() {
    add_management_page(
        'Логи валидации заказов',
        'Логи валидации',
        'manage_options',
        'checkout-validation-logs',
        'display_checkout_logs_page'
    );
}

function display_checkout_logs_page() {
    include_once(get_template_directory() . '/view-validation-logs.php');
}
```

## Типы записей

### INFO (Информация)
- Заполнение полей
- Создание заказа
- AJAX запросы

### WARNING (Предупреждения)
- Пустые обязательные поля
- Ошибки валидации на фронтенде

### ERROR (Ошибки)
- Критические ошибки валидации
- Ошибки JavaScript
- Проблемы с созданием заказа

### PROCESS (Процесс)
- Начало оформления заказа

## Диагностика проблем

### Форма не отправляется

1. Проверьте логи на наличие ошибок валидации
2. Убедитесь, что все обязательные поля заполнены
3. Проверьте, что скрытые поля заполняются корректно

### Ошибки JavaScript

1. Откройте консоль браузера (F12)
2. Проверьте логи на наличие JavaScript ошибок
3. Убедитесь, что все скрипты загружаются корректно

### Проблемы с валидацией

1. Проверьте, что поля не имеют атрибута `required`
2. Убедитесь, что валидация отключена для скрытых полей
3. Проверьте, что значения полей корректно передаются

### Изменение уровня логирования

В файле `checkout-validation-logger.php` можно настроить, какие события логировать:

```php
// Отключить логирование JavaScript ошибок
// Закомментируйте строку с add_action('wp_footer', ...)

// Отключить логирование AJAX запросов
// Закомментируйте строки с wp_ajax_woocommerce_checkout
```

### Изменение файла логов

```php
// В классе CheckoutValidationLogger измените:
self::$log_file = WP_CONTENT_DIR . '/your-custom-log-file.log';
```

## Безопасность

- ✅ Логи доступны только администраторам
- ✅ Чувствительные данные (nonce) не логируются
- ✅ Пароли и платежные данные не сохраняются
- ✅ Логи можно очистить через интерфейс

## Производительность

- ⚡ Логирование происходит асинхронно
- ⚡ Размер файла логов ограничен
- ⚡ Автоочистка старых записей
- ⚡ Минимальное влияние на скорость сайта

## Поддержка

При возникновении проблем:

1. Проверьте права доступа к файлу логов
2. Убедитесь, что директория `wp-content` доступна для записи
3. Проверьте, что WordPress может создавать файлы
4. Очистите кэш, если используется

## Пример использования

```php
// Добавьте в functions.php для подключения логирования
if (!class_exists('CheckoutValidationLogger')) {
    require_once(get_template_directory() . '/checkout-validation-logger.php');

// Добавьте страницу в админку

        'Логи валидации',

    );
```
