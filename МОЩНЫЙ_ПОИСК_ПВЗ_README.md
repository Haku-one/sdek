## Как использовать

### Обычное использование
- Поиск ПВЗ работает без ограничений - все найденные ПВЗ отображаются
- Расчет стоимости работает только через реальный API СДЭК

### Тестирование (админ панель)
В разделе настроек СДЭК доступны кнопки:
- **Проверить подключение** - проверка токена авторизации
- **Тестировать расчет стоимости** - проверка работы калькулятора

### Консольные команды для разработчиков
```javascript
// Показать статистику кэша
showPvzCacheStats()

// Очистить весь кэш
clearPvzCache()

// Обновить кэш для конкретного города
refreshPvzCache("Москва")
```

## Технические детали

### API расчета стоимости
- **Тариф**: 136 (Посылка склад-ПВЗ)
- **От**: Саратов (код 354)
- **До**: Автоопределение по выбранному ПВЗ
- **Без резервов**: При ошибке API = ошибка расчета

### Кэширование
- Ключ кэша: `pvz_${город.toLowerCase()}`
- Время жизни: 30 минут (1800000 мс)
- Автоматическая очистка при переполнении

### Производительность
- До 5000 ПВЗ с сервера
- До 99999 ПВЗ в списке (виртуализация)
- До 500 маркеров на карте одновременно
- Мемоизация запросов на 5 минут

### Стратегии поиска
1. Точный поиск по городу
2. Поиск по области/региону  
3. Поиск с префиксом "г."
4. Широкий поиск по России с фильтрацией
